# yaofish 鳐鳐鱼 官网首页

页面设计：李嘉易

## 设计思路

《山海经》里的文鳐鱼“鱼身而鸟翼”，常行西海，游于东海，以夜飞。整个页面就顺着这条鱼的路线来走：从天上的云，到人间的桌，再落进海里。

**天青流云**：主色取自 yaofish 品牌蓝，天空与海用同一种蓝串起来，底色是云白。全页没有硬朗的分割线，区块之间靠云和渐变过渡。

**云开见山**：打开页面时，云层遮住远处的仙山。向下滚动，云向两侧散开，字标随之浮现，一条丝带从山间画出，像打开一幅长卷。

**头条**：首屏之后是宽幅横幅，放最新上市的游戏和近期的大事，一眼就能看到品牌最新的动态。

**一家人，一张桌**：游戏用浅蓝的棋盘方格排列，像一张铺开的桌面，盒子安静地摆在上面；鼠标停留时才浮出名称、年龄、人数和时长，不打扰画面。

**鳐鳐鱼是谁**：品牌故事用竖排引出《山海经》原文，背后衬一个淡淡的大字“鳐”，流云随滚动缓缓漂移，回到传说本身。

**云下是海**：页脚是一片层层叠叠的海浪，由远及近升起。跃出水面的是鳐鳐鱼早期的 logo，它不时从浪后跃出，又落回浪里，算是向品牌的来处致意；在它跃起时点一下，它还会再跳高一点。
